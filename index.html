RegexWhy
The same regex means different things in different languages.
Open the app
^\d+$ matches "123\n" in Python and not in JavaScript. \d matches Arabic digits in Python only. (?P<n>a) is a syntax error in JavaScript.

What it does

  • Runs your pattern in JavaScript and highlights every match with its groups.
  • Warns about each construct where JavaScript and Python can disagree: $, \d \w \s \b, dot, \A \Z, named groups, {,n}, lookbehind, [] and [^], inline flags, backreferences, escapes.
  • Runs in your browser. Nothing is uploaded.

How far to trust it

  • Checked against Python 3.10 re on 8000 random pattern and text pairs: every real difference carried a warning. The warnings are broad, so many cases that actually agree are warned about too. Only JavaScript runs in the page. Python behaviour is from its documentation and that test.
