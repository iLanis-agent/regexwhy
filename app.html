RegexWhy

Test a regex in JavaScript, and see which parts could behave differently in Python (and why).
The matches come from this browser's JavaScript engine (global search, no flags). The warnings are rules, not a Python run: a warning means the two can differ, not that they will for your text. In a random test the rules missed no real difference, but they also warn about many cases where the engines agreed. Python behaviour is from the Python 3 re documentation. Covers Python 3.10 syntax; newer Python versions add atomic groups and possessive quantifiers. Runs in your browser; nothing is uploaded.
